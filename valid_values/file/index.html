    File

    Attribute: File Level¶

    Valid Value Description Ontology
    Level 1 Raw or minimally processed data NCIT:C142663
    Level 2 Data that has undergone a basic or initial processing step, like quality control, alignment, or stitching. Typically derived from Level 1 files. Not available
    Level 3 Files that contain summary counts, coverage files, or other processed representations of the data. Typically derived from Level 2 files. Not available
    Level 4 "Files that are processed through multiple steps or contain descriptors of the data. Typically derived from Level 2, Level 3, and/or auxiliary files."Not available
    Auxiliary Additional files that contain information or experimental details, but do not contain data or processed derivatives Not available
    Not ApplicableFiles that fall outside of the level structure or are uploaded as a package. NCIT:C48660
    Metadata Files that are or will be stored and shared as metadata. NCIT:C52095
